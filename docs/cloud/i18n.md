# 多语言（i18n）

OpenCode Manager 支持多语言，简体中文（`zh-CN`）作为一等语言维护。

## 已支持语言

| 代码 | 语言 | 状态 |
|------|------|------|
| `en` | English | 完整（默认回退） |
| `zh-CN` | 简体中文 | 完整（认证、设置、用户管理等核心界面） |

当前已本地化的界面：

- 登录 / 注册 / 初始化页（含登录前的语言切换）
- 设置：菜单与描述、通用设置（含语言切换器）
- 设置 → 用户（管理员账号管理）
- 校验错误、通用提示

其余功能界面（聊天、文件、Git、日志等）仍为英文，会按模块逐步迁移；由于采用
回退机制，缺少翻译的键会显示英文而不是报错。

## 语言选择与优先级

1. 用户在 **Settings → General → Language** 中的选择（写入 `localStorage: ocm.locale`）。
2. 登录页右上角的快捷切换。
3. 浏览器语言（`navigator.languages`，`zh*` → 简体中文）。
4. 默认 `en`。

## 技术实现

- 运行时：`i18next` + `react-i18next`
- 初始化：`frontend/src/lib/i18n/index.ts`（`initAsync: false`，保证首帧即为目标语言）
- 文案：`frontend/src/lib/i18n/locales/en.ts`、`zh-CN.ts`
- 语言列表与标签：`SUPPORTED_LOCALES`、`LOCALE_LABELS`

`zh-CN.ts` 的类型为 `DeepString<typeof en>`，因此**键结构必须与英文严格一致**，
漏键或拼错键会在 `tsc` 阶段直接报错。

## 在组件中使用

```tsx
import { useI18n } from '@/lib/i18n'

export function Example() {
  const { t, locale, setLocale } = useI18n()
  return <button onClick={() => setLocale('zh-CN')}>{t('common.save')}</button>
}
```

插值与复数：

```tsx
t('settings.users.memberCount', { count: users.length })
```

对应资源使用 i18next 复数后缀：

```ts
memberCount_one: '{{count}} user',
memberCount_other: '{{count}} users',
```

中文复数与英文同形，两个键都提供以避免回退到英文。

## 新增语言

1. 复制 `locales/en.ts` 为 `locales/<code>.ts` 并翻译。
2. 在 `locales/<code>.ts` 中把类型标注为 `DeepString<typeof en>`。
3. 在 `lib/i18n/index.ts` 的 `SUPPORTED_LOCALES`、`LOCALE_LABELS`、`resources` 中登记。
4. 运行 `pnpm --filter frontend typecheck` 校验键结构一致。

## 约定

- 只翻译用户可见文案；日志、接口字段、代码注释保持英文。
- 文案中不要拼接句子，整句作为一个键，避免语序问题。
- 日期使用 `toLocaleDateString()`，随浏览器区域设置格式化。
- 新增界面时同步补充 `en` 与 `zh-CN` 两个文件。
